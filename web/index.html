Build it locally

Gradle wrapper, Kotlin, Jetpack Compose. Debug APK installs alongside the release build.

# debug APK
./gradlew :app:assembleDebug

# unit tests + lint
./gradlew :app:testDebugUnitTest :app:lintDebug

# install on a device
adb install -r app/build/outputs/apk/debug/app-debug.apk

Targets, credentials and flags are fictional. The manifest declares no INTERNET permission, so commands can never leave the app.

Training simulator. No real shell, no exploit payload, and no capability to target systems outside the app. Only assess systems you own or are explicitly authorised to test.
